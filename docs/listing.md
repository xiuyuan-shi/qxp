## 工作概述

负责 100+ Listing 的日常维护与优化，覆盖标题、五点、长描述、关键词及主图 / A+ 页面，并结合广告、促销和合规事项开展商品运营。

## 本人工作

维护并优化标题、五点、长描述、关键词、主图和 A+ 页面；根据销售节奏及库存情况制定促销计划，并跟进相关合规 Case。

## 内容与搜索

优化标题、五点、长描述与关键词，持续维护商品详情页的信息表达。

## 视觉与页面

开展主图及 A+ 页面优化，熟练使用 Photoshop 等图片处理工具。

## 推广与促销

熟悉 SP、SB、SD 等广告类型，以及优惠券、折扣、Vine 等推广方式。

## 合规与协同

处理产品合规、账户合规及相关 Case，准备资料并跟进问题解决。

## 工作摘要

- 工作规模：100+ Listing
- 内容范围：文字、关键词、主图 / A+
- 协同事项：广告、促销与合规

标题 / 五点 / 长描述 / 关键词 / 主图 / A+ / 优惠券 / Vine / 合规 Case
